    Alles auf dieser Seite wird beim Klick berechnet: die Aufnahme wird aus einem Bewegungsmodell gerendert, durch dieselben vierzehn Schichten geschickt, die auch die Testsuite durchläuft, und das Ergebnis unverändert angezeigt. Es gibt keine vorbereiteten Ergebnisse und keinen Server — engine/playground/entry.ts ruft analyse() direkt auf.

    Die Bewegung ist simuliert, nicht gefilmt. Der Prüfstand zeigt damit, wie sich das System unter bekannten Bedingungen verhält — nicht, wie gut ein realer Pose-Schätzer auf realem Videomaterial arbeitet.
